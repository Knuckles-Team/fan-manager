# CONN-FAN-MANAGER — Requirements

Governing spec: [spec.md](spec.md).

Each row is one requirement. A row names the file it touches and the test that proves it.

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-FAN-MANAGER-R001` | **Ingest tools stay served.** The server must serve `fan_ingest_telemetry` as one tool per action on the Scion (SDK) split surface. | `tests/test_served_surface_keeps_ingest.py` rows R001.1 to R001.5 pass. |
| `CONN-FAN-MANAGER-R001.1` | **Ingest actions served.** The served set must contain `fan_ingest_telemetry_temperature` and `fan_ingest_telemetry_sensors`. | `tests/test_served_surface_keeps_ingest.py::test_ingest_telemetry_actions_are_served_as_tools` must pass. |
| `CONN-FAN-MANAGER-R001.2` | **Daemon loop is not a tool.** The served set must not contain a tool for `run_service`, because the daemon loop runs as the CLI service. | `tests/test_served_surface_keeps_ingest.py::test_run_service_is_not_a_tool` must pass. |
| `CONN-FAN-MANAGER-R001.3` | **Scion (SDK) floor.** The package must require `agent-connector-sdk[mcp]>=0.3.10,<1.0.0` in `pyproject.toml`, because older releases drop the ingest tools and ignore `EPISTEMIC_GRAPH_AUDIENCE`. | `tests/test_served_surface_keeps_ingest.py::test_sdk_floor_is_declared_for_the_split_surface` must pass. |
| `CONN-FAN-MANAGER-R001.4` | **Wiring.** `fan_manager/mcp_server.py:69` must call `register_tool_surface` with the temperature, fan-control, and knowledge-graph tool registries. | `tests/test_served_surface_keeps_ingest.py::test_client_lists_ingest_tools_through_the_real_server` must reach that call. |
| `CONN-FAN-MANAGER-R001.5` | **Hot-path proof.** An MCP client connected to the production server object must list 39 tools, including both ingest tools. | `tests/test_served_surface_keeps_ingest.py::test_client_lists_ingest_tools_through_the_real_server` must pass. |
| `CONN-FAN-MANAGER-R002` | **Per-node read endpoint.** When `FAN_MANAGER_NODE_API_PORT` is set, each fan-manager daemon must serve a read-only HTTP endpoint for its own server's BMC, from `fan_manager/node_api.py`. | `tests/test_fleet_endpoints.py` rows R002.1 to R002.3 pass. |
| `CONN-FAN-MANAGER-R002.1` | **Reads served, writes refused.** The node endpoint must answer `GET /health` and `GET /v1/<operation>`, and must answer 405 to every other method. | `tests/test_fleet_endpoints.py::test_node_endpoint_serves_reads_and_refuses_writes` must pass. |
| `CONN-FAN-MANAGER-R002.2` | **Read operations only.** The node operation set `READ_OPERATIONS` must name only BMC reads. It must not name a fan-level, power, boot, BMC user, LAN set, event-log clear, controller reset, or raw command. | `tests/test_fleet_endpoints.py::test_node_read_operations_are_reads_only` must pass. |
| `CONN-FAN-MANAGER-R002.3` | **Bearer token.** When `FAN_MANAGER_NODE_API_TOKEN` is set, every request except `/health` must carry that bearer token, or the endpoint must answer 401. | `tests/test_fleet_endpoints.py::test_node_endpoint_requires_the_token` must pass. |
| `CONN-FAN-MANAGER-R003` | **Connector aggregation.** When `FAN_MANAGER_HOSTS` and `FAN_MANAGER_NODE_URL_TEMPLATE` are set, the connector must send each in-band read to every node endpoint and return the answers keyed by node name, from `fan_manager/fleet.py`. | `tests/test_fleet_endpoints.py` rows R003.1 to R003.5 pass. |
| `CONN-FAN-MANAGER-R003.1` | **Temperature by node.** `fan_manager_get_temp` must return one answer per node, keyed by the name each node reports. | `tests/test_fleet_endpoints.py::test_connector_aggregates_temperature_by_node` must pass. |
| `CONN-FAN-MANAGER-R003.2` | **In-band IPMI reads by node.** An IPMI read tool called without `host` must go to every node endpoint. A read with `host` stays out-of-band to that BMC. | `tests/test_fleet_endpoints.py::test_connector_routes_inband_ipmi_reads` must pass. |
| `CONN-FAN-MANAGER-R003.3` | **Writes stay guarded.** The connector must never send a write to a node endpoint. A write needs an explicit out-of-band `host` and BMC credentials. | `tests/test_fleet_endpoints.py::test_connector_never_fans_out_writes` must pass. |
| `CONN-FAN-MANAGER-R003.4` | **Dead node is typed.** An unreachable node must appear as a 502 entry. The call must not raise. | `tests/test_fleet_endpoints.py::test_unreachable_node_is_reported_not_raised` must pass. |
| `CONN-FAN-MANAGER-R003.5` | **Node names to endpoints.** Each `FAN_MANAGER_HOSTS` name must map to an endpoint through `FAN_MANAGER_NODE_URL_TEMPLATE`; a URL entry is used as is. Without the template, reads stay local, because `FAN_MANAGER_HOSTS` alone also names hosts for the derivation pass. | `tests/test_fleet_endpoints.py::test_hosts_map_through_the_url_template` must pass. |
| `CONN-FAN-MANAGER-R004` | **Engine identity.** The trend ingest at `fan_manager/fan_manager.py:75` must sign engine requests as `EPISTEMIC_GRAPH_PRINCIPAL` with audience `EPISTEMIC_GRAPH_AUDIENCE`, read by the Scion (SDK). The DaemonSet names `service:fan-manager` and `agent-services`. | `tests/test_engine_identity.py::test_trend_ingest_signs_as_the_configured_principal_and_audience` must pass. |
| `CONN-FAN-MANAGER-R005` | **Ingest connector name.** The trend ingest binding at `fan_manager/kg_ingest.py` must name connector `fan-manager-mcp`, the name the engine has an imported pack for; any other name makes the engine refuse writes with `UNKNOWN_MAPPING_REFERENCE`. | `tests/test_ingest_connector_name.py::test_ingest_binding_uses_the_onboarded_connector_name` must pass. |
